<div align="center"><img src="https://www.google.com/search?q=https://placehold.co/800x300/000000/FFFFFF%3Ftext%3DAeroShield%26font%3Dsans" alt="AeroShield Banner"><h1>AeroShield - Real-Time Air Quality Index (AQI) Detector</h1><p><a href="https://www.google.com/search?q=https://github.com/your-username/aerosheild-aqi-detector/blob/main/LICENSE"><img src="https://www.google.com/search?q=https://img.shields.io/badge/License-MIT-yellow.svg" alt="License: MIT"></a><a href="https://opensource.org/"><img src="https://www.google.com/search?q=https://badges.frapsoft.com/os/v1/open-source.svg%3Fv%3D103" alt="Open Source"></a><a href="#"><img src="https://www.google.com/search?q=https://img.shields.io/badge/NASA%2520Space%2520Apps-2025-blue" alt="NASA Space Apps"></a></p></div>AeroShield is an interactive web-based dashboard that provides real-time Air Quality Index (AQI) data for any location in the world. With a user-friendly map interface, historical data visualization, and actionable health recommendations, AeroShield empowers users to stay informed about the air they breathe.🚀 Live Demo✨ Features🗺️ Interactive Map: Click anywhere on the map or use the search bar to get instantaneous AQI data.💨 Real-time AQI Data: Get up-to-date information on PM2.5 levels and the overall AQI.📊 24-Hour Historical Data: View a chart of the AQI trend over the last 24 hours for any selected location.❤️ Health Recommendations: Receive personalized health advice based on the current AQI level.🎨 Color-Coded Legend: Easily understand the air quality levels with a clear, color-coded legend.🔥 Heatmap View: Visualize AQI hotspots in different regions.📍 "My Location" Button: Instantly get the AQI for your current location.🌓 Light & Dark Mode: Switch between themes for your viewing comfort.📱 Responsive Design: Fully functional on both desktop and mobile devices.💻 Technologies UsedCategoryTechnologyFrontendHTML5, CSS3, JavaScript, Leaflet.js, Chart.jsBackendNode.js, Express.js, CORS, dotenvAPIsOpenWeatherMap Air Pollution API, OpenStreetMap Nominatim🛠️ Setup and InstallationTo get a local copy up and running, follow these simple steps.PrerequisitesNode.js and npm installed. You can download them here.An API key from OpenWeatherMap.InstallationClone the repository:git clone [https://github.com/your-username/aerosheild-aqi-detector.git](https://github.com/your-username/aerosheild-aqi-detector.git)
cd aerosheild-aqi-detector
Install NPM packages for the server:npm install
Create a .env file in the root directory and add your API key:OWM_KEY=your_openweathermap_api_key
Start the backend server:npm start
The server will be running on http://localhost:5010.Open index.html in your browser to view the application.🚀 UsageOpen the application in your browser.Search for a location: Use the search bar to find a specific city or address.Click on the map: Tap anywhere on the map to get the AQI details for that point.Use "My Location": Click the "📍 My Location" button for data on your current position.The info panel will display the current AQI, a 24-hour historical chart, and health recommendations.📸 ScreenshotsLight ModeDark ModeFully responsive design for mobile devices.🤝 ContributingContributions make the open-source community an amazing place to learn, inspire, and create.
